# wedo911.github.io

The landing page for my open-source work — a single index of every tool,
in **English and Arabic**, with a live link and a source link for each.

**→ https://wedo911.github.io/**

Built because a good tool nobody can find helps nobody. Each project used
to live in its own repository with its own URL and no way to discover the
others; this page is the hub that ties them together, and its
[`sitemap.xml`](sitemap.xml) points search engines at all 26 live pages
from one place.

Static, no build step, no dependencies, no tracking.
